# Bounceback

A modern AI-inspired schedule and productivity dashboard web app.

## Run locally

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Features
- Accuracy analytics (daily/weekly/monthly/yearly)
- Productivity score and streak tracking
- Interactive line/pie/bar charts (canvas)
- Heatmap calendar intensity view
- Task scheduling with category, priority, recurring, and goal type
- Task completion + archiving (no deletion)
- Drag-and-drop task reordering
- Light/dark mode and responsive glassmorphism UI
- LocalStorage persistence across refresh/restart
